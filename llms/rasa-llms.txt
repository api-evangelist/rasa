# Rasa

> Rasa is an open-core conversational AI framework for enterprises that natively leverages generative AI (CALM — Conversational AI with Language Models) to build reliable text and voice assistants. Rasa Pro is the pro-code framework; Rasa Studio is the no-code UI. The runtime is self-hosted and exposes an HTTP API plus a custom-action SDK.

## APIs
- [Rasa HTTP API (Server Endpoints)](https://rasa.com/docs/reference/overview/): Retrieve and modify conversation trackers, train/test/load models, parse messages. OpenAPI 3.0.1. Default server http://localhost:5005.
- [Rasa SDK Action Server](https://rasa.com/docs/): Single POST / endpoint (call_action) that Rasa Core calls to run custom actions. OpenAPI 3.0.2.
